# 📝 版本更新记录

## v1.2.11

#### ✨ 新增功能

- **独立 Web 浏览器播放引擎（`playMode: "web"` + `webPlayback`）**：
  - 新增完全独立的 Web 浏览器播放引擎 `WebPlaybackSession`，与原有 `legacy` 播放逻辑完全隔离；支持在 `playids.playMode`、`musician.play.playMode`、`fansgroup.playMode`、`sign.yunbeiTask.playDailyRecommendMode` 以及 WebUI 策略配置中按需切换（默认保持 `legacy`）；
  - 沙箱 Cookie 自动执行 `web_clean` 隔离（剥离 `os`/`appver`/`deviceId` 等客户端字段，保留 `sDeviceId`），并自动补齐与持久化网页前端标识 Cookie（`WNMCID`、`WEVNSM=1.0.0`、`_ntes_nuid`、`%2C` 编码的 `_ntes_nnid`、`_iuqxldmzr_=33`、`ntes_kaola_ad=1`），确保 `clientlogusf.music.163.com/weapi/feedback/weblog` 播放上报稳定计入周榜、总榜、最近播放与 `listenSongs`；
  - 支持 `chunked` 边播边分片拉流（默认 256KB/片、目标 1800KB）、100 秒绝对网格心跳（`pl/count` + `impress`）、`standard`/`exhigh` 音质选择及 `ui`/`playend` 上报模式；
  - `ncmm playids` 新增 `--play-mode`、`--only`、`--count`、`--verify-rank`、`--rank-only` 参数，可一键验证播放前后的听歌周榜、总榜、最近播放（`/weapi/play-record/song/list`）及 `listenSongs` 差值。
- **官方 URS 网页手机验证码登录（CLI + WebUI）**：
  - 新增 `pkg/urs` 纯 Go 实现（SM4-ECB-PKCS#7 + VDF + MurmurHash3），完整接入网易云官网 URS 手机短信验证码登录流程；
  - `ncmm login phone` 默认使用 `--mode web` 启动本地一次性易盾验证页（支持 `--addr` 自定义监听地址），同时保留 `--mode pc` 旧版 EAPI 通道；
  - WebUI 账号中心「手机验证码」默认采用 **Web 网页模式（推荐）**，点击「获取验证码」后按需弹出居中易盾安全滑块弹窗（独立同源 iframe 作用域 CSP，不放宽主页面策略），通过后自动发短信并签发纯净网页版 Cookie（含全部网页前端标识字段）。
- **WebUI 远端系统公告与通知弹窗**：
  - WebUI 顶栏新增系统公告铃铛入口（支持未读红点提示与公告列表弹窗），支持按公告级别、优先级、适用版本区间与生效时间自动弹出重要公告；
  - 支持「不再提示此公告」、稍后提醒、手动刷新（带冷却防抖）及已读确认状态本地持久化；
  - 在 WebUI「系统设置」新增「接收远端公告」开关（默认开启，也可通过环境变量 `NCMM_NOTICE_DISABLE` 强制禁用），关闭后不再请求远端公告源。
- **代理池管理与账号代理绑定默认开启**：
  - 代理池功能调整为**默认开启**（新装与旧版升级用户均可在 WebUI 侧边栏直接进入「代理池」配置节点与绑定账号），支持静态 `http`/`socks5` 代理节点与 Resin 网关，未配置节点时默认直连且不自动生成冗余文件；
  - 如需全局禁用代理池并强制直连，可在 `proxies.yaml` 中显式写入 `enabled: false`（运行期实时生效，无需重启）。
- **乐迷团点赞笔记自动取消点赞（`fansgroup.autoUnlikeNote`）**：
  - 新增 `/api/resource/unlike`（`ResourceUnlike`）接口封装，并在 `fansgroup` 配置段及 WebUI 乐迷团配置页新增 `fansgroup.autoUnlikeNote` 开关（默认 `true`，支持手动关闭）；
  - 乐迷团「点赞乐迷笔记」任务升级为两阶段执行：先逐条完成点赞（成功间隔 **1–4 秒**，失败退避 1–2 秒），全部点完后等待 **4–6 秒**给服务端异步记账留足缓冲，再按原点赞顺序（FIFO）逐条取消本次成功点赞的帖子（每条间隔 **2–4 秒**），并支持任务取消时即时退出。

## v1.2.8

#### 🛡️ 风控安全与核心优化
- **播放任务 `play.webSession` 彻底废弃与运行时安全锁**：
  - 因网易云风控机制升级，剔除 Cookie 中的 `os` 字段会被判定为异常流量导致播放任务报风控异常；
  - 现已将 `play.webSession` 配置彻底废弃，运行时强制锁定为 `false`，播放类任务（如 `playids` 指定歌曲播放等）不再剔除 `os` cookie，杜绝风控拦截；
  - WebUI 参数配置界面同步将该选项标记为 `[已废弃]` 并给出风险预警说明。
- **历史配置智能升级与自动降级脱敏**：
  - 检测到配置文件版本 `< 1.2.8` 时，系统自动在配置升级过程中将旧配置中遗留的 `play.webSession: true` 和 `fansgroup.webSession: true` 强制安全重置为 `false`，写回文件并更新为新版本号；
  - **向下兼容历史版本**：对更早版本（如 < 1.2.5 尚未引入该字段）的老配置，自动补全最新模板注释并采用安全的默认值 `false`，绝不因字段缺失报错；
  - **支持后期按需手动开启**：完成升级后，若用户确需使用乐迷团网页端会话且未遇风控，可在配置文件或 WebUI 中手动将 `fansgroup.webSession` 设为 `true`，系统会永久保留该手动设置且不会被后续启动二次篡改。

#### 🚀 CI/CD 发布流水线架构重构
- **新建统合流水线 `Release & Quality Pipeline`**：
  - 将质量检测（Quality Checks）、Docker 镜像构建与 GitHub Release 打包流程整合为统一的 DAG 依赖流水线；
  - **质量门禁安全熔断**：发布流程前置执行完整的自动化测试（Go 单元测试、Race 竞态检测、WebUI 语法与 Playwright 浏览器端到端测试）。一旦测试报错，流水线立即在第一步中止，后续镜像与构件发布完全被跳过（Skipped），**彻底杜绝带病发布**；
  - **双通道并行提速**：质量门禁通过后，Docker 镜像构建推送与 GitHub Release 打包同步并行执行，保持发布耗时最短；
  - **保留独立手动触发**：原有各独立工作流仅保留 `workflow_dispatch` 手动触发，方便随时单跑排查。

#### 🐞 Bug 修复
- **修复接口鉴权与 Docker 健康探测冲突导致 CI 检查失败的问题**：
  - 修复此前为兼容 Docker 老版 Launcher 健康检查而将 `/api/v1/status` 设为公开免鉴权，导致安全测试用例未拦截携带 Bearer token 的非法凭据而报 `want 401, got 200` 的问题；
  - 收紧放行条件：仅在本地回环直连且未携带任何凭据头时才豁免老版 Launcher 探针，外部远程网络与携带非法 Authorization 头的请求一律严格鉴权拦截。
- **插件市场与版本记录修复**：
  - 从在线插件市场移除私有插件 ；
  - 修复在线安装插件时未能将实际 release tag 存入 `source.json` 导致本地插件版本号显示滞后的问题。
